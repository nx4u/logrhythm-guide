AIE Compound

Brute Force Followed by Success

Objective: Detect repeated failed authentication followed by successful login for the same user.

Sources: Windows Security, VPN, Identity Provider.

Logic: Threshold Observed: failed logins ≥ 5 within 10 minutes, then Log Observed: successful login within 5 minutes.

Group By: User + Source IP. Response: Review IP, confirm with user owner, reset password or disable account if suspicious.

Threshold

Password Spray

Objective: Detect one source trying many users with low failure count per account.

Sources: Windows Security, VPN, IdP.

Logic: Unique Values Observed: many destination users from same Source IP within a short window.

Group By: Source IP. Response: Check external/internal source, block IP, validate impacted users.

Operational

Critical Log Source Stopped Sending

Objective: Detect missing logs from high-value log sources.

Sources: LogRhythm platform events, collection status, source inventory.

Logic: Not Observed Scheduled: no logs from critical source within expected interval.

Group By: Host + Log Source. Response: Check Last Log Date, source availability, System Monitor, firewall, and scsm.log.

Behavioral

First Time Admin Login to Server

Objective: Detect unusual privileged access.

Sources: Windows Security, AD group events, server logs.

Logic: Whitelist rule: profile approved admin-to-server patterns, alert on new pair.

Group By: User + Host. Response: Validate change ticket, check privilege escalation and lateral movement.

Platform

AIE Alarm Spike

Objective: Identify noisy AIE rules causing alarm fatigue.

Sources: AIE events and alarms.

Logic: Threshold: AIE alarm count above baseline for a rule name within a time window.

Group By: Rule Name. Response: Tune criteria, thresholds, whitelist, or workload.

Collection

Syslog Volume Drop

Objective: Detect loss of incoming Syslog traffic.

Sources: Firewall, network devices, Linux syslog.

Logic: Trend or threshold not observed based on normal log volume.

Group By: Log Source + Host. Response: Wireshark udp.port == 514, verify destination IP/port/protocol.

قاعدة مهمة في AIE TuningImportant AIE Tuning Rule

لا تعتمد على حدث واحد إذا كان بإمكانك تأكيده بحدث آخر. استخدم Compound Rules و Group By و Whitelist لتقليل False Positives.Do not rely on one event when you can corroborate it with another. Use compound rules, Group By, and whitelist logic to reduce false positives.
