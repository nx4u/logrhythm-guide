Search Patterns

مكتبة استعلامات LogRhythmLogRhythm Query Library

نماذج بحث جاهزة وقابلة للتعديل. عدّل أسماء الحقول حسب بيئتك وطريقة البحث في Web Console أو Client Console.Ready search patterns. Adjust field names to match your environment and search interface.

UsePatternNotes
Failed LoginsCommon Event contains "Logon Failure" AND User = <user>Use before building brute-force logic.
Successful LoginCommon Event contains "Logon Success" AND Host = <host>Correlate after failures.
Password SpraySource IP = <ip> AND Common Event contains "Logon Failure"Group results by User.
Stopped SourceLog Source = <source> AND time range = last 24hCompare with Last Log Date.
Syslog CheckHost = <device> AND Protocol IN (UDP,TCP)Pair with Wireshark: udp.port == 514.
AIE EventsEvent Name starts with "AIE" OR Rule Name = <AIE Rule>AIE events are distinguished by AIE naming.
Privileged LoginUser IN <admin_group> AND Common Event contains "Logon Success"Review against approved admin activity.
Notification IssueAlarm Name = <alarm> AND Notification Status = failureThen review scarm.log.
Missing Search DataHost = <host> AND Log Source = <source>Validate collection, processing, then indexing.

Useful Windows Log IDs

Use these only where your MPE parsing and Windows audit policy support them.

  • 4624 successful logon
  • 4625 failed logon
  • 4720 user account created
  • 4728/4732 added to privileged group

Search Workflow

  1. Start with Common Event or Classification.
  2. Add entity filters: user, host, source IP, destination IP.
  3. Expand the time window.
  4. Pivot from normalized fields to raw log.
  5. Save as investigation evidence.
