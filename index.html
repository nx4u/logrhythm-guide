Consultant Notes

كيف يفكّر المستشار الخبير؟How does the consultant think?

ابدأ من عرض المشكلةStart from the symptom

  • لا توجد لوقات؟ غالباً المشكلة Collection أو Parsing.No logs? Usually a collection or parsing issue.
  • اللوقات موجودة لكن لا تظهر في البحث؟ افحص DX وWeb Indexer.Logs present but not searchable? Inspect DX and the Web Indexer.
  • الـ alarm لا يصل بالبريد؟ افحص ARM و Notification Policy وSMTP.Alarm email not arriving? Check ARM, Notification Policy, and SMTP.

ثم اربطها بمسار اللوقThen map it to the log path

إذا عرفت أين توقفت الرسالة داخل المسار، غالباً ستعرف أي ملف لوق وأي خدمة تراجعها أولاً.If you know where the message stopped in the pipeline, you usually know which log file and service to inspect first.
