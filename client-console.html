Client Console Walkthrough

شرح Client Console للمسؤولClient Console Walkthrough for Administrators

Client Console هي واجهة الإدارة الأساسية. منها تدير Deployment Manager، Hosts، Log Sources، System Monitors، AIE Rules، Alarm Rules، والتقارير.Client Console is the primary administration interface. Use it for Deployment Manager, Hosts, Log Sources, System Monitors, AIE Rules, Alarm Rules, and reports.

Daily Admin Paths

أهم المسارات داخل Client ConsoleKey Client Console Paths

Deployment Manager → Hosts

هنا تدير تعريف الأجهزة. لا تضيف Log Source بدون فهم الـ Host المرتبط به، لأن الـ Host هو سياق المصدر داخل LogRhythm.Manage host records here. Do not add a log source without understanding its Host context.

Deployment Manager → System Monitors

هنا تضيف أو تعدّل الـ Agents ومصادر اللوق المرتبطة بها. هذا المسار مهم في Windows collection وSyslog وFlat File.Add or adjust agents and their log sources here. This is critical for Windows collection, Syslog, and flat files.

AI Engine Rule Wizard

استخدمه لبناء Rule Blocks. ركز على Primary Criteria، Data Filters، Group By، Relationship Time Limit، والـ Actions.Use it to build rule blocks. Focus on Primary Criteria, Data Filters, Group By, Relationship Time Limit, and Actions.

Alarm Rules → Notify

عند مشاكل الإشعارات، افحص من يتم إشعاره: Person أو Role أو Group، ثم راجع Notification Policy وSMTP.For notification issues, inspect who is notified: Person, Role, or Group, then validate Notification Policy and SMTP.

إضافة Log Source بطريقة صحيحةAdding a Log Source Correctly

حدد نوع المصدرIdentify source type

Windows Event Log, Syslog, Flat File, API, UDLA.

حدد الـ System Monitor المناسبChoose the right System Monitor

اختيار agent غلط يعني أن اللوق لن يصل أو سيظهر من سياق خاطئ.Wrong agent selection means the log may not arrive or may appear in the wrong context.

أضف المصدر من خصائص الـ AgentAdd source from Agent properties

المسار النموذجي: Deployment Manager → System Monitors → Agent Properties → New Log Message Source.Typical path: Deployment Manager → System Monitors → Agent Properties → New Log Message Source.

تحقق من النتيجةValidate the outcome

لا تكتفي بالحفظ. تحقق من Last Log Date، حجم اللوق، raw log، parsed metadata، والبحث في Web Console.Do not stop after saving. Validate Last Log Date, volume, raw log, parsed metadata, and Web Console search.
