Daily Health

  • Open Deployment Monitor.
  • Check host/service status.
  • Review database utilization.
  • Validate DX search health.
  • Review high/critical alarms.

Collection Health

  • Critical sources Last Log Date.
  • Log volume spikes/drops.
  • System Monitor service status.
  • Recent scsm.log errors.
  • Recent onboarding changes.

AIE Health

  • AIE service running.
  • Rule sets enabled as expected.
  • No unusual alarm spike.
  • Review tuning candidates.
  • Check workload if delayed.
