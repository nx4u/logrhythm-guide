Troubleshooting

التروبلشوتنق حسب المكوّنComponent-Based Troubleshooting

رتبت الأعطال حسب مكان المشكلة داخل المنصة حتى يكون التحليل أسرع وأوضح.Issues are grouped by platform stage so analysis is faster and clearer.

System Monitor

No Logs / Remote Collection Fails

  • Check the System Monitor service status
  • Review scsm.log for access denied / failed to open event log
  • Validate service account permissions and Event Log Readers membership
  • Confirm firewall and connectivity to the remote host
  • For flat files: validate path, permissions, directory settings, and timestamp parsing
Data Processor

Logs Arrive but Are Not Parsed

  • Review scmedsvr.log and scmpe.log
  • Confirm the device is mapped to the correct Log Source Type
  • Validate whether an MPE rule is matching
  • Search for raw logs and compare against parsed metadata
Data Indexer

Search Missing Data

  • Check columbo.log, carpenter.log, and bulldozer.log
  • Review disk health and indexer service state
  • Compare data arrival time with search visibility
AI Engine / ARM

Rule Does Not Trigger or Email Does Not Send

  • Confirm the AIE rule is enabled and logically correct
  • Validate Group By, time limit, thresholds, and metadata availability
  • Check lraieengine.log and lraiecommgr.log
  • If event exists but no notification: inspect scarm.log, SMTP, notify tab, policy, and recipients
