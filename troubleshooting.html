دليل سريع حسب العرض أو رسالة الخطأ أو المكوّن. اتبع Life of a Log ولا تقفز مباشرة للنهاية.A quick guide by symptom, error message, and component. Follow the Life of a Log instead of jumping to the end.

Failed to open event log

Likely area: Windows Remote Collection / System Monitor.

  1. Check System Monitor service account.
  2. Validate Event Log Readers membership and permissions.
  3. Check firewall/RPC access.
  4. Review scsm.log after restarting System Monitor.

RPC server unavailable

Likely area: Network path between Agent and Windows host.

  1. Validate host is reachable.
  2. Check Windows Firewall inbound rules.
  3. Confirm required ports are not blocked.
  4. Test with Event Viewer from collector host.

Syslog not received

Likely area: Source configuration, network, or listener.

  1. Confirm destination IP, port, and protocol on the source device.
  2. Capture traffic with Wireshark using udp.port == 514 or tcp.port == 514.
  3. Check listener and Log Source mapping.
  4. Review scsm.log.

Flat file not collected

Likely area: Path, permissions, or parsing format.

  1. Restart System Monitor and watch first scsm.log errors.
  2. Validate absolute file path.
  3. Confirm account can read folder and files.
  4. Validate date parsing format and directory options.

AIE Rule not triggering

Likely area: Rule logic, metadata, or workload.

  1. Confirm rule is enabled.
  2. Search for expected metadata first.
  3. Validate Rule Block criteria and Group By.
  4. Check Relationship Time Limit.
  5. Review lraieengine.log and lraiedp.log.

Alarm notification not received

Likely area: ARM, Notify tab, or SMTP.

  1. Open Alarm Rule > Notify tab.
  2. Validate Person/Role and group membership.
  3. Confirm SMTP address and Notification Policy.
  4. Review scarm.log for ARM errors.
