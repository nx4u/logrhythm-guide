Troubleshooting

من العرض إلى السبب الجذريFrom symptom to root cause

Use the data path instead of guessing.

No logs

Collection path

  • Verify source is sending.
  • Check firewall and transport.
  • Review scsm.log.
  • Validate permissions for remote Windows collection.
No search

Processing / Indexing path

  • Check MPE parsing.
  • Review Data Processor logs.
  • Check Data Indexer logs.
  • Compare raw logs to searchable metadata.
No alert

AIE path

  • Confirm rule is enabled.
  • Validate Group By and relationship time.
  • Confirm required metadata exists.
  • Review lraieengine.log.
No email

ARM path

  • Confirm AIE event or alarm exists.
  • Review scarm.log.
  • Validate notification policy and SMTP.
  • Check people/roles/group membership.
