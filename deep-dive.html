Life of a Log

مسار اللوق الذي يحل 80% من المشاكلThe log path that solves most issues

1

Collect

هل المصدر يرسل؟ هل System Monitor يستقبل؟ هل scsm.log فيه أخطاء؟Is the source sending? Is System Monitor receiving? Does scsm.log show errors?

2

Process

هل الـ DP طابق MPE rule واستخرج metadata؟Did the DP match an MPE rule and extract metadata?

3

Store / Search

هل DX فهرس البيانات وهل البحث يعرضها؟Did DX index the data and does search show it?

4

Correlate

هل AIE شاف metadata المطلوبة؟ هل Group By والمنطق صحيح؟Did AIE see the required metadata? Are Group By and logic correct?

5

Alert / Notify

هل AIE event موجود؟ إذا موجود ولا يوجد بريد، اتجه إلى ARM.Does the AIE event exist? If yes but email did not send, go to ARM.

6

Investigate

التحقيق يكون من Web Console مع pivots على user, host, IP, event.Investigation happens in Web Console with pivots on user, host, IP, and event.

Methodology

منهجية المستشارConsultant methodology

1

Define the symptom

No logs, delayed logs, no search results, no AIE event, or no notification.

2

Map to the pipeline

Collection, processing, indexing, correlation, or notification.

3

Use the right evidence

Service logs, Deployment Monitor, search results, AIE events, and ARM logs.

4

Change one thing

Avoid changing rule logic, schedules, whitelists, and notifications at the same time.

Mistakes

أخطاء شائعةCommon mistakes

Blaming AIE too early

Validate metadata before blaming correlation.

Ignoring ARM

A rule can fire while notification fails.

No runbook

An alert without triage steps is operational debt.
