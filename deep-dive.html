Life of a Log

المسار التشغيلي للّوقOperational Log Path

Log Source

مصدر اللوق قد يكون Windows Event Log أو Firewall أو VPN أو Proxy أو ملف flat file. أهم سؤال هنا: هل المصدر ينتج اللوق فعلاً وهل يرسله إلى الوجهة الصحيحة؟The source may be Windows Event Log, Firewall, VPN, Proxy, or flat file. Key question: is the source generating logs and sending them to the right destination?

System Monitor

System Monitor هو طبقة التجميع. عند أي مشكلة وصول، ابدأ بـ scsm.log، الصلاحيات، الخدمة، ومنفذ Syslog أو طريقة الـ pull.System Monitor is the collection layer. For arrival issues, start with scsm.log, permissions, the service state, and the Syslog or pull method.

Data Processor / MPE

هنا يتحول اللوق الخام إلى metadata قابلة للبحث والربط. إذا وصل اللوق لكن التصنيف أو الحقول غلط، غالباً المشكلة في Log Source Type أو MPE Rule.Raw logs become searchable/correlatable metadata here. If logs arrive but fields are wrong, inspect Log Source Type and MPE matching.

Data Indexer

مسؤول عن persistence والبحث. إذا البيانات موجودة في المنصة لكن لا تظهر في البحث، افحص DX وWeb Indexer والـ indexing delay.Responsible for persistence and search. If data exists but search misses it, inspect DX, Web Indexer, and indexing delay.

AI Engine

AIE لا يحلل raw text فقط؛ يعتمد على metadata parsed. لذلك أي نقص في parsing سيؤثر مباشرة على Rule Blocks وGroup By.AIE depends on parsed metadata, not merely raw text. Missing parsing directly impacts rule blocks and Group By.

Platform Manager / ARM

PM/ARM يحول الحدث إلى alarm أو notification أو SmartResponse. إذا ظهر AIE Event ولم يصل الإيميل، لا ترجع للـ SysMon؛ افحص ARM وSMTP والسياسات.PM/ARM turns events into alarms, notifications, or SmartResponse actions. If an AIE Event exists but email fails, inspect ARM, SMTP, and policies.

Component Deep Dive

شرح المكونات كخبيرComponents Explained Like a Consultant

Collection

System Monitor

لا تحكم أن المنصة لا تعمل قبل التأكد من أن System Monitor يستقبل أو يسحب البيانات. افصل بين مشكلة source لا يرسل ومشكلة agent لا يقرأ.Do not blame the platform before validating whether System Monitor receives or pulls data. Separate “source not sending” from “agent cannot read”.

Key log: scsm.log
Check: service, permissions, listener, last log date
Processing

Data Processor

Data Processor هو المكان الذي تتحول فيه الرسالة إلى معنى. راقب MPE، التصنيف، الـ metadata، ومؤشرات الضغط.Data Processor is where a message becomes meaning. Watch MPE, classification, metadata, and load indicators.

Key logs: scmedsvr.log, scmpe.log, lraiedp.log
Search

Data Indexer

DX ليس مجرد تخزين؛ هو طبقة البحث والتحليل. المشاكل تظهر كـ missing search results أو بطء أو تأخير.DX is not just storage; it is the search analytics layer. Problems show as missing results, slowness, or lag.

Key logs: columbo.log, carpenter.log, bulldozer.log
Correlation

AI Engine

AIE يربط أحداث متعددة عبر الوقت والمصادر. جودة القاعدة تعتمد على جودة metadata، Group By، والـ Relationship Time Limit.AIE correlates multiple events over time and sources. Rule quality depends on metadata, Group By, and Relationship Time Limit.

Key logs: lraieengine.log, lraiecommgr.log
Response

ARM

ARM هو مسار الإنذار والإشعار. لا تخلط بين rule triggered وبين notification delivered؛ كل واحدة لها مسار تحقق.ARM handles alarm and notification flow. Do not confuse “rule triggered” with “notification delivered”; each has a separate validation path.

Key log: scarm.log
Operations

Consoles

Client Console للإدارة العميقة، Web Console للعمل اليومي للمحلل. استخدام الواجهة الصحيحة يوفر وقت كبير.Client Console is for deeper administration; Web Console is for analyst daily work. Choosing the right interface saves time.

Admin = Client Console
SOC Triage = Web Console

Field Lessons

أخطاء شائعة في مشاريع LogRhythmCommon LogRhythm Project Mistakes

Mistake

تفعيل قواعد كثيرة بدون baseline أو tuning.Enabling too many rules without baseline or tuning.

Impact

Alarm fatigue، فقدان الثقة، وتجاهل التنبيهات المهمة.Alarm fatigue, loss of trust, and missed important alerts.

Fix

ابدأ بـ top use cases، ثم عدّل thresholds وGroup By وwhitelists.Start with top use cases, then tune thresholds, Group By, and whitelists.

Mistake

اعتبار وصول اللوق إلى SysMon نهاية الـ onboarding.Treating arrival at SysMon as complete onboarding.

Impact

البيانات قد لا تكون parsed أو searchable أو alertable.Data may not be parsed, searchable, or alertable.

Fix

تحقق من Last Log Date، raw log، metadata، search، وAIE eligibility.Validate Last Log Date, raw log, metadata, search, and AIE eligibility.
