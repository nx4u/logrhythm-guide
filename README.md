# LogRhythm Guide v4

Arabic/English LogRhythm SIEM reference site for SOC analysts, SIEM administrators, and support engineers.

## What is included

- `index.html` — platform overview, Life of a Log, Client Console vs Web Console
- `deep-dive.html` — consultant-style deep explanation of LogRhythm architecture and troubleshooting thinking
- `client-console.html` — Client Console walkthrough and admin paths
- `platform-manager.html` — Platform Manager, ARM, reports, jobs, and notification troubleshooting
- `use-cases.html` — practical AIE detection use cases
- `queries.html` — search and investigation starters
- `troubleshooting.html` — component-based troubleshooting
- `checklists.html` — daily health, incident triage, onboarding, and tuning checklists
- `assets/` — built-in SVG diagrams, no external image dependency

## Repository description

Bilingual LogRhythm SIEM field guide for SOC operations, AIE detection engineering, platform administration, troubleshooting, and daily health checks.

## GitHub Pages deployment

1. Upload all files to the root of the repository.
2. Go to **Settings > Pages**.
3. Select **Deploy from a branch**.
4. Select branch `main` and folder `/root`.
5. Save and open the generated GitHub Pages URL.

## Notes

This is a learning and field-reference site. It is not an official LogRhythm or Exabeam site. Validate any configuration changes in a test environment before production.
