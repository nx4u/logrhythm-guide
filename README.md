# LogRhythm Guide v6

A premium, consultant-style bilingual Arabic/English LogRhythm SIEM reference site for GitHub Pages.

## What's new in v6

- More polished product-doc style design.
- Rebuilt `deep-dive.html` with official LogRhythm documentation images where available.
- Added `components.html` and `aie.html`.
- Added external official images with local SVG fallback.
- Cleaner navigation and improved page structure.
- Better Arabic/English language toggle persistence.
- More consultant-style explanations instead of short notes.

## Official image handling

The site embeds public images from LogRhythm/Exabeam documentation and uses a local SVG fallback if those images fail to load.
